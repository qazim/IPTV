# 📺 TurkAzeri IPTV

Azərbaycan və Türkiyə telekanallarının pulsuz yayım siyahısı. Bu layihə sizə sevdiyiniz kanalları istənilən IPTV pleyerində izləməyə imkan verir.

## 📡 Kanal Siyahıları

### 🇦🇿🇹🇷 Azərbaycan və Türkiyə Kanalları
Birgə yayım siyahısı üçün:
```
https://qazim.github.io/IPTV/TurkAzeri.m3u
```

### 🇦🇿 Yalnız Azərbaycan Kanalları
Yalnız azərbaycanlı kanallar üçün:
```
https://qazim.github.io/IPTV/all_channels.m3u
```

## 🛠 Necə İstifadə Etmək?

1. **IPTV Pleyerini Yükləyin**: Aşağıdakı pleyerlərdən birini seçin:
   - VLC Media Player (Windows, Mac, Linux)
   - IPTV Smarters (Android, iOS)
   - TiviMate (Android TV)
   - GSE Smart IPTV (iOS, Android)

2. **Linki Əlavə Edin**:
   - Pleyerinizi açın
   - "M3U URL" və ya "Playlist" bölməsinə yuxarıdakı linklərdən birini daxil edin
   - Kanalları izləməyə başlayın!

## 📱 Dəstəklənən Cihazlar

- Smart TV-lər (Samsung, LG, Sony)
- Android və iOS cihazları
- Kompüterlər (Windows, macOS, Linux)
- TV Box-lar və Android TV

## ⚠️ Qeyd

- Bütün kanallar pulsuz və ictimai mənbələrdən təmin edilir.
- Yayım keyfiyyəti internet sürətinizdən asılıdır.
- Bəzi kanallar zaman-zaman mövcud olmaya bilər.
